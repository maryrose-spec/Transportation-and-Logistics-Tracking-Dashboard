# Transport and Logistics Data Analysis Using Python

## Project Overview

This project analyzes 1000 logistics records using Python to identify delivery patterns, customer feedback trends, and operational delays.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Regex
- WordCloud
- Jupyter Notebook

## Key Objectives

- Analyze customer reviews
- Identify delay patterns using Regex
- Visualize logistics performance
- Generate insights from shipment data

## Project Visualizations

1. Delivery Delay Distribution
2. Shipping Mode Analysis
3. Customer Review WordCloud

## Key Findings

- Delivery delays varied across shipment routes
- Shipping methods influenced delivery performance
- Customer feedback highlighted recurring delay factors
